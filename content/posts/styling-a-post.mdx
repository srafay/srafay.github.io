This post sets its own colours. Switch between light and dark mode to see both palettes, then open any other page: the site's usual colours come back.

## Three levels of control

1. **`theme`** in the metadata overrides the site's colour tokens, separately for light and dark mode.
2. **`css`** in the metadata adds any CSS you like, for this page only. Scope it with `[data-post="your-slug"]` if you only want to touch the article.
3. **Components.** Posts are MDX, so you can import a React component and use it inline:

<Callout>This box is a React component imported by this post alone.</Callout>

## Tokens you can override

`--background`, `--surface`, `--foreground`, `--muted-foreground`, `--border`, `--signal` and `--link`.
